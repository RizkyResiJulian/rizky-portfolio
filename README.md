# Rizky Resi Julian — Interactive Portfolio

Next.js portfolio with a dark futuristic visual system, interactive hero, recruiter-focused project case studies, experience timeline, editable placeholder assets, and Vercel/GitHub-ready structure.

## Run
```bash
npm install
npm run dev
```

## Replace assets
- `public/images/profile-placeholder.svg` → your photo
- `public/images/logos/*.svg` → real company/institution logos
- `public/images/projects/*-placeholder.svg` → real project screenshots
- `public/cv/rizky-resi-julian-cv.pdf` → real CV PDF

## Update personal links
Edit `app/page.tsx` and replace LinkedIn/GitHub/email values.

## Deploy
Push to GitHub, then import the repository into Vercel. No special build command is required beyond the default Next.js settings.
